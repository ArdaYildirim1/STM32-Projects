# STM32 External Interrupt (EXTI)

External interrupt (EXTI) implementation on the STM32F407-Discovery board using a push button.

## What It Does

- LEDs blink sequentially in a chase pattern in the main loop.
- Pressing the user button (Button_Pin, PA0) triggers an interrupt on the EXTI0 line.
- When the interrupt occurs, `HAL_GPIO_EXTI_Callback` runs, turning off all LEDs and applying a short delay.

## Concepts Covered

- **EXTI (External Interrupt):** A hardware interrupt line tied to a GPIO pin.
- **NVIC (Nested Vectored Interrupt Controller):** Manages interrupt priorities and enabling/disabling of interrupt lines.
- **Rising Edge Trigger:** The interrupt fires when the button signal transitions from LOW to HIGH.
- **HAL_GPIO_EXTI_Callback:** A weak (overridable) callback function that runs when the interrupt occurs.

## Hardware

- Board: STM32F407G-DISC1 (STM32F407VG)
- Button: Onboard user button (PA0)
- LEDs: LD3, LD4, LD5, LD6 (onboard)

## Note

This project includes the default pin configuration generated by CubeMX for the STM32F407-Discovery board (USB OTG, I2C/MEMS sensor, I2S/audio codec settings, etc.). The focus of this project is the Button_Pin EXTI configuration in `MX_GPIO_Init()` and the `stm32f4xx_it.c` / `HAL_GPIO_EXTI_Callback` sections; the remaining peripheral settings come from the board's default template.
