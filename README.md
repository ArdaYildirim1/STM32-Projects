# 🚀 STM32 Projects Portfolio

Welcome to my STM32 projects repository! This workspace is dedicated to my journey in embedded systems and microcontrollers. Here, you will find a structured collection of my work, ranging from low-level hardware interactions to higher-level hardware abstraction layer implementations.

Most of the projects here are developed and tested on the **STM32F4DISCOVERY** board.

## 📂 Repository Structure

To keep things clean and easy to navigate, I have divided my projects into two main categories based on the development approach:

### 🛠️ 1. Bare-Metal Projects (`/BareMetal_Projects`)
This directory contains projects where I interact directly with the microcontroller's registers. It showcases a deep understanding of the hardware architecture without relying on external abstraction libraries. Inside, you will find fundamental Embedded C exercises, custom driver implementations from scratch, and low-level peripheral configurations.

### 🧩 2. HAL Projects (`/HAL_Projects`)
This directory includes projects developed using the STM32 Hardware Abstraction Layer (HAL) library. It focuses on rapid prototyping, clean code architecture, and utilizing ST's official drivers. Projects in this folder cover various peripheral implementations such as ADCs, Timers, PWM generation, hardware interrupts, and comprehensive GPIO control.

## ⚙️ Tools & Environment
* **Microcontroller:** STM32F407VG (STM32F4 Discovery Board)
* **Language:** C / C++
* **IDE:** STM32CubeIDE
